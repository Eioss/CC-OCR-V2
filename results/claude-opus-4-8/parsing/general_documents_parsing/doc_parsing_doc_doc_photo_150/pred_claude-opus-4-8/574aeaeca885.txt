# 期权交易经纪合同（节选）

```latex
\documentclass{article}
\usepackage{CJKutf8}
\usepackage{enumitem}

\begin{document}
\begin{CJK}{UTF8}{gbsn}

\begin{enumerate}[label=\arabic*、]
    \item 乙方是依法设立的期权经营机构，具有相应的期权经纪业务资格；
    \item 乙方具有开展期权经纪业务的必要条件，能够为甲方的期权交易提供相应的服务；
    \item 乙方承诺遵守有关法律、法规、规章、上海证券交易所（以下简称上交所）以及中国证券登记结算有限责任公司（以下简称中国结算）业务规则，不接受投资者的全权交易委托，不对投资者的投资收益或亏损进行任何形式的保证，不编造或传播虚假信息误导投资者，不诱使投资者进行不必要的期权交易；
    \item 乙方承诺遵守本合同，按本合同为甲方提供期权交易经纪服务。
\end{enumerate}

\noindent\textbf{第二条\qquad 甲方向乙方作如下声明和承诺：}

\begin{enumerate}[label=\arabic*、]
    \item 甲方具有合法的期权投资资格，不存在法律、法规、规章、上交所及中国结算的业务规则禁止或限制其进行期权交易的情形；
    \item 甲方保证在其与乙方本合同关系存续期内向乙方提供的所有证件、资料均真实、准确、完整、合法，并保证其资金来源合法；
    \item 甲方已阅读并充分理解乙方向其提供的《风险揭示书》、《投资者须知》，清楚认识并愿意承担期权市场投资风险；甲方已详细阅读本合同所有条款，并准确理解其含义，特别是其中有关乙方的免责条款；
    \item 甲方承诺遵守有关法律、法规、规章、上交所及中国结算的业务规则，遵守乙方投资者适当性管理相关制度和要求；
    \item 甲方承诺遵守本合同，并承诺遵守乙方的相关管理制度。
\end{enumerate}

\noindent\textbf{第三条\qquad} 甲方委托乙方从事期权交易，保证所提供的证件及资料具有真实性、合法性及有效性。甲方声明并保证不具有下列情形：

\begin{enumerate}[label=（\chinese*）]
    \item 无民事行为能力或者限制民事行为能力的自然人；
    \item 中国证监会及其派出机构、中国期货业协会、中国证券业协会、上交所、中国结算、期权保证金安全存管监控机构、期权经营机构的工作人员及其配偶；
    \item 国家机关、事业单位；
    \item 证券、期货市场禁止进入者；
    \item 未能提供真实、合法、有效开户证明文件的单位或个人；
    \item 中国证监会及上交所规定不得从事期权交易的其他单位或个人。
\end{enumerate}

\end{CJK}
\end{document}
```
