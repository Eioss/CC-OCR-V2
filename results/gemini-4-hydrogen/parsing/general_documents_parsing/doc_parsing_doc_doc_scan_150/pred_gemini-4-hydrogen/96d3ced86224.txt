% Main Title
\noindent{\Large\bfseries\color{awinicblue} Functional Description}

\vspace{10pt}

\noindent
The AW350X5D/AW350X5 is a P channel MOSFET power distribution switch with current limit function. In addition, the switch also features fast short-circuit response, under voltage lockout, over temperature protection and reverse current protection.

\vspace{12pt}

\noindent\textbf{\large CURRENT LIMIT THRESHOLD SETTING}

\vspace{6pt}

\noindent
The AW35005D/025D/035D/045D/055D/005/025/035/045/055 provides fixed current limit threshold. The current limit function can prevent the switch from over current condition.

\vspace{4pt}

\noindent
The minimum current limit is 400mA, beyond 2.5A is forbidden.

\vspace{8pt}

\begin{center}

\vspace{10pt}

\noindent\textbf{\large FAST SHORT CIRCUIT PROTECTION}

\vspace{6pt}

\noindent
The AW350X5D/AW350X5 provides short circuit protection function which can limit the output current to a safe level without damaging the switch.

\vspace{12pt}

\noindent\textbf{\large UNDER VOLTAGE LOCKOUT (UVLO)}

\vspace{6pt}

\noindent
The AW350X5D/AW350X5 has under voltage lockout function which can disable the switch until the input voltage reaches the UVLO threshold (typical 2.3V). The UVLO threshold has a 95mV hysteresis voltage which can prevent the unwanted on/off cycling when there is noise on the input voltage.

\vspace{12pt}

\noindent\textbf{\large OVER TEMPERATURE PROTECTION (OTP)}

\vspace{6pt}

\noindent
When the junction temperature exceeds 155$^\circ$C, the internal OTP circuit turn off the power switch. There is a temperature hysteresis 25$^\circ$C, in other words, the OTP circuit can turn on the switch only if the junction temperature is below 130$^\circ$C.

\vspace{12pt}

\noindent\textbf{\large QUICK OUTPUT DISCHARGE}

\vspace{6pt}

\noindent
The AW35005D/AW35025D/AW35035D/AW3545D/AW35055D include the Quick Output Discharge (QOD) feature, in order to discharge the application capacitor connected on OUT pin. When EN pin is set to low level, a discharge resistance with a typical value of 75$\Omega$ is connected between the output and ground, pull down the output and prevent it from floating when the device is disabled.

\vspace{12pt}

\noindent\textbf{\large REVERSE CURRENT PROTECTION (RCP)}

\vspace{6pt}

\noindent
The AW350X5D/AW350X5 includes the Reverse Current Protection(RCP) function, which can prevent the current to flowing through the P-FET or the body diode when $\mathrm{V_{OUT}}$ greater than $\mathrm{V_{IN}}$. Whatever the switch is on or off, the AW350X5D/AW350X5 always has this function. When $\mathrm{V_{OUT}}$-$\mathrm{V_{IN}}$ greater than $\mathrm{V_{REV}}$, the internal comparator quickly turns off the switch, in order to prevent large reverse current from $\mathrm{V_{OUT}}$ to $\mathrm{V_{IN}}$. The switch will return to normal operation once the reverse voltage scenario disappeared.

\vspace{6pt}

\noindent
The $\mathrm{I_{REV\_ACT}}$ parameter in the figure 6 can be calculated by the following formula: $\mathrm{I_{REV\_ACT}} = \dfrac{\mathrm{V_{REV}}}{\mathrm{R_{dson}}}$
