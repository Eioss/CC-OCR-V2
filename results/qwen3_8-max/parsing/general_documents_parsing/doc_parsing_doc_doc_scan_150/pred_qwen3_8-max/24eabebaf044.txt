\begin{itemize}
    \item \textbf{Single Task} refers to a request that involves only one task. We consider the planning to be correct when and only when the task name (i.e., \texttt{"task"}) and the predicted label are identically equal. F1 and accuracy are chosen as evaluation metrics for single-task scenarios.
    
    \item \textbf{Sequential Task} represents that the intent of the user request can be decomposed as a sequence of multiple sub-tasks. Here, we use F1 and normalized Edit Distance [35] as the metrics.
    
    \item \textbf{Graph Task} indicates that user requests can be decomposed into directed acyclic graphs. Considering the possibility of multiple planning topologies within graph tasks, only using F1-score is not enough to reflect the LLM capability in planning. To address this, following Vicuna [36], we employed GPT-4 as a critic to evaluate whether the planning is correct. The accuracy is obtained by evaluating the judgment of GPT-4, referred to as the GPT-4 Score. Detailed information about the GPT-4 Score can be found in Appendix A.1.5.
\end{itemize}
