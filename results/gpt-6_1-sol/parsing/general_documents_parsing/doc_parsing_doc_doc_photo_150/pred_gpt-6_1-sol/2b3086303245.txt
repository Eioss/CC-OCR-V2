3. \textbf{State whether the following are true or false}

\noindent
If variable Y and X (a regressor variable) are strongly statistically associated then we can predict
Y from X reasonably accurately.

\medskip
\noindent
In all cases, in a SLR model, if variable Y and X are strongly statistically associated then X
causes Y.

\medskip
\noindent
If a test for the X coefficient in the model `\(Y=\beta_0+\beta_1x\)' shows that it is non-significant, then we
can use the mean of Y as an estimate for Y at any valid value of X.

\medskip
\noindent
`Regressor' and `predictor' are synonyms for `independent variable' in a SLR model.
