## **Trigonometry**

### 1) Trigonometry Ratios:
$$ \text{Sine} = \frac{\text{Opp}}{\text{Hyp}} $$
$$ \text{Cos}\theta = \frac{\text{Adj}}{\text{Hyp}} $$
$$ \tan\theta = \frac{\text{Opp}}{\text{Adj}} $$
$$ \text{Cot}\theta = \frac{\text{Adj}}{\text{Opp}} $$
$$ \text{Sec}\theta = \frac{\text{Hyp}}{\text{Adj}} $$
$$ \text{Cosec}\theta = \frac{\text{Hyp}}{\text{Opp}} $$

*(Diagram of a right-angled triangle with vertices A, B, C. Angle at B is $90^\circ$. Side AB is Opp, Side BC is Adj, Side AC is Hyp)*

### 2) Imp. Results :
i) $\text{Sin}\theta.\text{Cosec}\theta = 1$
ii) $\text{Cos}\theta.\text{Sec}\theta = 1$
iii) $\tan\theta.\text{Cot}\theta = 1$
iv) $\tan\theta = \frac{\text{Sin}\theta}{\text{Cos}\theta}$
v) $\text{Cot}\theta = \frac{\text{Cos}\theta}{\text{Sin}\theta}$
vi) $\sin^2\theta + \cos^2\theta = 1$
vii) $\sec^2\theta = 1 + \tan^2\theta$
viii) $\text{Cosec}^2\theta = 1 + \cot^2\theta$
ix) $\pi^c = 180^\circ$
x) length of arc $s = r\theta$
xi) Area of sector $= \frac{1}{2}s\theta$ *(Note: Image has smudge/tear here, likely $\frac{1}{2}r^2\theta$ or similar, transcribed as visible)*

### 4) Allied - Angles :
1) $\sin(-\theta) = -\sin\theta$
   $\cos(-\theta) = \cos\theta$
   $\tan(-\theta) = -\tan\theta$
   $\cot(-\theta) = -\cot\theta$
   $\sec(-\theta) = \sec\theta$
   $\text{cosec}(-\theta) = -\text{cosec}\theta$

2) $\sin(90^\circ-\theta) = \cos\theta$
   $\cos(90^\circ-\theta) = \sin\theta$
   $\tan(90^\circ-\theta) = \cot\theta$
   $\cot(90^\circ-\theta) = \tan\theta$
   $\sec(90^\circ-\theta) = \text{cosec}\theta$
   $\text{cosec}(90^\circ-\theta) = \sec\theta$

### 5) Compound Angles :
1) $\sin(A+B) = \sin A \cos B + \cos A \sin B$
2) $\sin(A-B) = \sin A \cos B - \cos A \sin B$
3) $\cos(A+B) = \cos A \cos B - \sin A \sin B$
4) $\cos(A-B) = \cos A \cos B + \sin A \sin B$
5) $\tan(A+B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$
6) $\tan(A-B) = \frac{\tan A - \tan B}{1 + \tan A \tan B}$

### 6) Multiple Angle and Sub Multiple Angle :
$\sin 2A = 2\sin A \cos A$
$\cos 2A = \cos^2 A - \sin^2 A$
$\cos 2A = 2\cos^2 A - 1$
$\cos 2A = 1 - 2\sin^2 A$
$\tan 2A = \frac{2\tan A}{1 - \tan^2 A}$

i) $\sin A = 2\sin(\frac{A}{2})\cos(\frac{A}{2})$
ii) $\cos A = \cos^2(\frac{A}{2}) - \sin^2(\frac{A}{2})$
iii) $\cos A = 1 - 2\sin^2(\frac{A}{2})$
iv) $\cos A = 2\cos^2(\frac{A}{2}) - 1$
v) $\cos A = \frac{1 - \tan^2(\frac{A}{2})}{1 + \tan^2(\frac{A}{2})}$
vi) $\sin A = \frac{2\tan(\frac{A}{2})}{1 + \tan^2(\frac{A}{2})}$
vii) $\tan A = \frac{2\tan(\frac{A}{2})}{1 - \tan^2(\frac{A}{2})}$
viii) $1 + \cos A = 2\cos^2(\frac{A}{2})$
ix) $1 - \cos A = 2\sin^2(\frac{A}{2})$

### 7) Triple Angle Formulae :-
i) $\sin 3\alpha = 3\sin\alpha - 4\sin^3\alpha$
ii) $\cos 3\alpha = 4\cos^3\alpha - 3\cos\alpha$
iii) $\tan 3\alpha = \frac{3\tan\alpha - \tan^3\alpha}{1 - 3\tan^2\alpha}$
iv) $\cos^3\alpha = \frac{\cos 3\alpha + 3\cos\alpha}{4}$
v) $\sin^3\alpha = \frac{3\sin\alpha - \sin 3\alpha}{4}$

### 8) Factorization Formulae :-
i. $\sin C + \sin D = 2 \sin(\frac{C+D}{2}) \cos(\frac{C-D}{2})$
ii. $\sin C - \sin D = 2 \cos(\frac{C+D}{2}) \sin(\frac{C-D}{2})$
iii. $\cos C + \cos D = 2 \cos(\frac{C+D}{2}) \cos(\frac{C-D}{2})$
iv. $\cos C - \cos D = 2 \sin(\frac{C+D}{2}) \sin(\frac{D-C}{2})$ If $C>D$
   $= 2 \sin(\frac{C+D}{2}) \sin(\frac{D-C}{2})$ If $D>C$

### 9) Defactorization formulae :-
i. $2 \sin A \cos B = \sin(A+B) + \sin(A-B)$
ii. $2 \cos A \sin B = \sin(A+B) - \sin(A-B)$
iii. $2 \cos A \cos B = \cos(A+B) + \cos(A-B)$
iv. $2 \sin A \sin B = \cos(A-B) - \cos(A+B)$

## Co - Ordinate - Geometry (2D)

1. Distance Formula : $\sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$
2. Section Formula : $P(x,y) = (\frac{mx_1+nx_2}{m+n}, \frac{my_1+ny_2}{m+n})$ Internally
   $Q(x,y) = (\frac{mx_1-nx_2}{m-n}, \frac{my_1-ny_2}{m-n})$ Externally
3. Mid point Formula : $(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2})$
4. Centroid of triangle : $G(\frac{x_1+x_2+x_3}{3}, \frac{y_1+y_2+y_3}{3})$
5. Area of triangle $= \frac{1}{2} [x_1(y_2-y_3) + x_2(y_3-y_1) + x_3(y_1-y_2)]$
6. Slope of straight line : $m = \tan\theta$
7. One point Form : $y-y_1 = m(x-x_1)$
8. Slope Intercept from : $y = mx + c$
9. Two point Form : $\frac{y-y_1}{y_2-y_1} = \frac{x-x_1}{x_2-x_1}$
10. Intercept Form : $\frac{x}{a} + \frac{y}{b} = 1$
11. Normal Form : $x \cos\alpha + y \sin\alpha = p$
12. Slope of line $ax + by + c = 0$ is $-\frac{a}{b}$
13. Intersection fo two lines : $L_1 + \lambda L_2 = 0$
14. Angle between two s.t. lines : $\tan\theta = |\frac{m_1-m_2}{1+m_1m_2}|$
    If the lines are parallel ; $m_1 = m_2$
    If the lines are $\perp$ ; $m_1.m_2 = -1$
15. Length of 'l' form : $\frac{ax_1+by_1+c}{\sqrt{a^2+b^2}}$
16. Bisector Equations : $\frac{a_1x+b_1y+c_1}{\sqrt{a_1^2+b_1^2}} = \pm \frac{a_2x+b_2y+c_2}{\sqrt{a_2^2+b_2^2}}$
17. Distance betw parallel lines : $\frac{|c_1-c_2|}{\sqrt{a^2+b^2}}$
18. Homogeneous Equation : $ax^2 + 2hxy + by^2 = 0$
    $\tan\theta = \frac{2\sqrt{h^2-ab}}{a+b}$
19. General Equation : $ax^2 + 2hxy + by^2 + 2gx + 2fy + c = 0$ represents a pair of lines
    If $abc + 2fgh - af^2 - bg^2 - ch^2 = 0$
    Point of intersection $(x,y) = (-\frac{hf-bg}{ab-h^2}, \frac{hg-af}{ab-h^2})$

## Co - Ordinate - Geometry (3D)

1. Distance Formula : $\sqrt{(x_1-x_2)^2 + (y_1-y_2)^2 + (z_1-z_2)^2}$
2. Section Formula : $(\frac{mx_1+nx_2}{m+n}, \frac{my_1+ny_2}{m+n}, \frac{mz_1+nz_2}{m+n})$ Internally
